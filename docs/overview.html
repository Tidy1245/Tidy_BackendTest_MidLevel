✦ 租戶隔離機制

每筆請求的租戶解析流程

從 HTTP Header 到資料庫 WHERE 條件，全程自動化，Repository 層零感知。

📩 HTTP Request X-Tenant-Id: T001
→
🔀 TenantMiddleware 讀取 Header，設定 ITenantContext.TenantId
→
⚙️ Application Service 呼叫 Repository，不需帶 TenantId 參數
→
🛡 AppDbContext HasQueryFilter 自動附加 WHERE TenantId = 'T001'
→
🗄 SQL Server 只回傳屬於 T001 的資料列
💡 關鍵設計

ITenantContext 以 Scoped 生命週期注入 AppDbContext。 EF Core 的 HasQueryFilter() 在 OnModelCreating 時以 lambda 捕捉 _tenantContext 引用， 每次查詢執行時動態讀取當前 TenantId，實現零侵入式隔離。
